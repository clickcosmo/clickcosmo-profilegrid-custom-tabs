=== ProfileGrid Custom Tabs ===
Requires at least: 6.0
Requires PHP: 7.4
License: GPLv2 or later
License URI: https://www.gnu.org/licenses/gpl-2.0.html

Adds configurable custom tabs to ProfileGrid user profiles without modifying ProfileGrid core.

== Features ==
* Unlimited custom profile tabs.
* Text, HTML, and shortcode content.
* Drag-and-drop tab ordering.
* Everyone, logged-in, or profile-owner visibility.
* Optional ProfileGrid group restrictions.
* Optional icon CSS class.
* Uses ProfileGrid's native extension hooks.

== Installation ==
1. Install and activate ProfileGrid.
2. Install and activate ProfileGrid Custom Tabs.
3. Open ProfileGrid > Global Settings > Extensions Settings > Custom Profile Tabs.
4. Add, configure, and save tabs.
